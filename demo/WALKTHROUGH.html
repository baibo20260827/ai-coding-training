讲师演示与故障恢复脚本

版本：1.0。建议 20–25 分钟，实际时间待试讲。配合 需求追踪 与 运行说明。

演示准备

  • 使用虚构姓名、主题和本地新数据库；先运行自动测试与故障演练。
  • 检查端口、浏览器访问、字号投影和数据库文件路径。保留一份已验证的项目副本。
  • 选择尚无预约的一天（下面固定为 2026-10-08）；如果已有数据，改用全新 --db 路径。不得为了重演而删除不认识的记录。
  • 明确这是教学基线，无客户已批准承诺，也没有真实审批功能。遇到工具失败，如实展示，转到已保存的验证记录并解释记录不是本次现场结果。

第一幕：一句话需求怎样成为验收（3 分钟）

讲：“客户说要能预约。我们补充了单会议室、时间边界、冲突规则、保存和取消，才有办法判断完成。”

展示 R01–R08，重点圈出 A03 相邻允许/重叠拒绝、A05 刷新保留、A08 同时预约最多一条成功。问听众：其中哪一条看页面截图无法证明？

第二幕：运行并验收（5 分钟）

启动：python3 demo/app.py --port 8765，访问 http://127.0.0.1:8765。

操作 预期观察 对应
日期选 2026-10-08，预约 10:00–11:00 成功，列表出现虚构姓名及主题 A01/A02
浏览器刷新；随后停止服务并用同一 --db 重启 刷新和重启后记录都在 A05
预约 11:00–12:00 成功，相邻允许 A03
预约 10:30–11:30 提示冲突，列表没有新增记录 A03
取消 10:00–11:00 并确认，再次建立同一预约 取消后释放，新预约成功 A04
将结束时间选到开始时间之前 提示明确，数据库不增加记录 A06

说明：“页面操作提供一个观察角度。并发、异常请求、边界和回归要交给合适的检查。”不在现场录入真实员工姓名或客户资料。

第三幕：测试全绿为何仍会错（5 分钟）

运行 python3 demo/labs/failure_lab.py。

  1. 旧实现把时间当闭区间，错误拒绝相邻预约。
  2. 错误修复只判断完全相同的时段，同时把一条重叠测试预期改为允许。弱测试 3/3 绿。
  3. 从需求基线独立取出的验收例子发现“部分重叠”和“包含”错误。
  4. 正确区间规则通过 4 条例子，主应用实际事务也通过相邻与冲突检查。
  5. 页面内存模型重建后 0 条，重新连接持久化数据库仍有 2 条。明确这是模型模拟；真实刷新看上一幕。

讲：“本脚本中的错误是预先编写的教学故障，并非记录某次模型行为。测试预期变更应有业务依据，审查要同时看代码和预期。”

脚本 exit 0 表示演练按预期发现故障。可分别指向 old_conflict、wrong_fix、ACCEPTANCE，比较代码与独立验收来源。

第四幕：把约束放进可执行机制（4 分钟）

运行 python3 -m unittest discover -s demo/tests -v。指出数据库并发与 HTTP 并发测试，不将运行速度当作容量评估。

画出“预约 → 多个半小时占用槽”：10:00–11:00 占 10:00 与 10:30 两行；11:00 起始槽未被占用。两个请求争用同一个槽时，事务与唯一约束只允许一个完成。失败时整笔回滚，不能留下部分占用。取消通过级联删除释放槽。

讲：“任务说明提出规则，测试验证行为，数据库事务与约束落实行为；AGENTS.md 无法代替它们。”

第五幕：恢复与交付判断（3–5 分钟）

运行 python3 demo/backup.py exercise。展示备份有 1 条、原库取消后 0 条、新恢复库 1 条；原库保留，覆盖现有目标被拒绝。

真实演示库的备份与恢复按 README 命令进行，必须新文件名。代码回退与数据恢复分开；主应用版本、schema 版本和快照时间应一起记录。

最后让三类受众各提交一个动作：主管写一句有依据的状态报告；工程师给出接受/退回及证据；新手写一个可复现问题或验收结果。进入新增审批的变更演练时说明：下一步展示影响分析，不声称应用已经实现审批。

现场问题处理

现象 先检查 验证完成方式
页面打不开 终端是否在运行、端口是否一致、有无本机监听限制 页面与 /api/health 可访问，再验证一条业务场景
看不到刚才记录 日期、当前 --db 路径、是否提交成功 同一天 GET 列表和浏览器刷新一致
预约失败 错误提示；重叠、日期、粒度及起止顺序 合法请求成功，非法请求没有残留
恢复脚本拒绝目标 目标是否已存在、源是否本教学数据库 保留原文件，换新路径，检查恢复内容
测试不能监听端口 沙箱/终端是否允许本地服务 记录环境限制，获准环境运行接口测试；不要改成跳过后称全部通过

记录实际用时、听众误解与需改进处，交给项目改进日志。现场未完成的检查保持待执行。
