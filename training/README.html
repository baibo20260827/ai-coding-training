培训使用入口

本套材料用于部门软件工程 harness 与 AI coding 能力建设。版本 v1.0，制作日期 2026-10-03。案例及管理演练为虚构教学场景；实际运行检查见项目证据目录，真实客户验收与培训成效需在试点中取得。

先选学习路径

受众 PPT 阅读与实践 建议时长与目标
部门主管 主管课件 主管指南、练习 L1/L5/L6 75 分钟；能依据证据决定范围、日期、资源与推广
资深开发者 工程师课件 工程师指南、练习 L2/L3/L4 150 分钟；能委派、独立验证、定位与恢复
无编码经验者 新手课件 新手指南、练习 L1/L2/L4 150 分钟；能拆分小需求、验收结果和说明问题

时长是备课建议，需要按试讲结果调整。三套课程均从三个小失败开始。同一批学员连续参加多条路线时，共同开篇只讲一次。

讲师按此顺序准备

  1. 阅读讲师运行手册，确定学习对象、时间、协助人员和验收方式。
  2. 按案例运行说明启动本地应用并检查功能；练习使用专用教学数据库。
  3. 备好对应 PPT、学员练习、参考答案和AI 任务卡。参考答案在练习完成后讲解。
  4. 使用材料与模板索引找到需求、4A、部署、DfX、周报、变更及能力考核材料。
  5. 将实际问题送入FAQ所述流程，试讲改动记录到改进日志。

学员需要准备什么

  • 可运行 Python 3 的电脑和浏览器。案例无需 pip/npm 安装，具体版本与命令以案例 README 为准。
  • 一个能够阅读和编辑项目文件的工具；使用部门准入的 AI coding 工具参与练习。代码运行本身不依赖模型服务。
  • Windows 中若没有 python3，按案例说明使用 py -3 或相应启动文件。所有命令都在项目根目录执行。
  • 不方便运行代码的主管，可以用已填的虚构周报、变更示例和演示观察记录完成决策练习。
