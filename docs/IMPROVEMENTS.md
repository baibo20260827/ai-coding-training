## 新改进记录模板

- 编号、日期、来源、问题/新增要求、适用场景。
- 受影响对象：受众、需求、架构、代码、文档、PPT、模板、验收或承诺。
- 原因与证据：区分实际观察、假设和待调查事项。
- 改进动作、负责人、变更位置；若调整已确认客户承诺，链接变更决策依据。
- 验证方法、实际结果及证据；未执行项与遗留限制。
- 状态：待分析 / 已纳入方案 / 已实施待验证 / 已验证 / 延后并注明原因。
- 下一步：需要谁在何时提供何种信息或采取何种行动；没有约定日期时标为待定。
