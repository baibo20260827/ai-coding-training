自动检查

命令：python3 -m unittest discover -s demo/tests -v，从项目根目录运行。

首轮在受限沙箱执行：15 项数据库、业务、并发与恢复测试通过；6 项 HTTP 测试因 socket.bind 返回 PermissionError: [Errno 1] Operation not permitted 未能开始。记录为执行环境限制，未改写为通过。

随后获准在本机回环地址运行临时 HTTP 测试服务，重新执行完整命令。实际终端摘要：

Ran 21 tests in 0.241s

OK

结果：21/21 通过、exit code 0。0.241 秒只记录该轮运行耗时，不作为性能基准。

覆盖：

  • 日期过滤和排序、建立与取消、SQLite 重新连接后持久化。
  • 相邻允许；相同、部分重叠、包含时段拒绝；失败事务不残留占用。
  • 无效日期、时间、类型、字数、控制字符、JSON 和请求大小；参数化 SQL 将输入作为数据。
  • HTTP 页面与资源、健康接口、201/200/400/403/404/409/413/415 等主要行为。
  • 本地绑定、Host/Origin 限制、无跨站 OPTIONS 与路径白名单。
  • 8 个数据库并发竞争：1 成功、7 冲突；3 个相邻并发均成功。
  • 4 个 HTTP 并发竞争：1 个 201、3 个 409，最终仅 1 条预约。
  • 新文件备份与恢复、拒绝覆盖已有目标、拒绝接管其他 SQLite 数据库。

完整可执行定义：test_app.py。
