## 内容修订与覆盖

- 三套课程统一从主管、高手、新手各自的小失败开篇，明确故事为虚构教学情境。
- 课时统一为 75/150/150 分钟；学习效果与实际时长保持待试讲。
- BA/AA/DA/TA 对齐案例实现，数据主键为字符串 id，占用格以 `(day,start_minute)` 唯一约束，事务内整体写入/回滚。
- 需求基线到 A01—A08 验收、代码、自动检查及演示形成对应。
- 变更演练区分工作量和历时，原 D10、新预测 D12—D14 仅为已标注假设，并非真实获批延期。
- 午休变更练习保留原检查目的，按获准新规则适配受影响输入；没有修改原工程基线或冒充学员完成练习。
- 部署只列客户对齐事项，DfX 只说明目标、负责人、验证和证据，按用户要求保持概要。

## 验证限制与真实状态

- 初次 HTTP 测试因沙箱绑定限制受阻，获准本机回环执行后 21 项通过；原记录保留。
- HTML 手册完成静态结构、目录/链接与生成内容检查。当前 Browser 的 URL 策略拒绝 `file://`，未绕过；离线手册的浏览器视觉、查找交互和打印分页未实测。实际教学应用通过正常本机 HTTP 入口完成了浏览器验证。
- PPTX 已做 Artifact Tool 导入和渲染；没有在 PowerPoint 或 Google Slides 应用内打开、编辑与保存。
- 工程实测环境为 macOS；Windows/Linux 操作入口给出说明，但未执行平台验证。
- 尚无真实客户批准、部门人员能力考核、试讲反馈、收益或正式部署数据。相关模板和建议不能代替这些事实。

上述限制用于指导试讲前的检查，不改变本轮材料与本地案例已形成的状态。后续验证保留新环境、实际命令、结果和日期，不覆盖既有历史。
